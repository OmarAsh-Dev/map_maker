# map_maker v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows desktop map customizer/exporter (mapbuilder.app clone on OpenFreeMap tiles) that styles map categories, crops a region, and exports flat PNG or layered PSD/PNG up to 16k, packaged as a zip containing an unsigned exe.

**Architecture:** Electron app (electron-vite scaffold) with a React renderer hosting a MapLibre GL map plus a Tailwind feature-tree sidebar; a hidden offscreen MapLibre instance renders crop chunks tile-by-tile (mask passes per category/labels), streams chunk PNGs over IPC to the main process where `sharp` composites them and `ag-psd` assembles the PSD. All editing happens through the MapLibre style spec.

**Tech Stack:** Electron + electron-vite, React 18 + TypeScript, Tailwind CSS v4, maplibre-gl, zustand, sharp, ag-psd + node-canvas, vitest + Testing Library, electron-builder (zip target).

**Spec:** `docs/superpowers/specs/2026-10-19-map-maker-design.md` (read it first; this plan argues from it)

## Global Constraints

- OpenFreeMap tiles only — **no API key, ever, do not ask**; style URLs like `https://tiles.openfreemap.org/styles/liberty`.
- Map view strictly top-down: pitch locked at 0; bearing rotation allowed.
- Export long edge capped at **16,384 px**.
- Deliverable: electron-builder **zip** target, NSIS disabled, exe **unsigned**.
- Attribution default-on; removable only after warning dialog (ODbL/ToS text per spec).
- Tile fetching: ≤4 parallel requests, disk cache, User-Agent starting `map_maker/`.
- All style edits via MapLibre style spec; edits are pure functions returning new style objects.
- Every task: `npm test` and `npm run typecheck` pass before commit.

## Review Focus

1. **Chunk seams at fractional zoom** — chunks must tile exactly with no gaps/overlaps at non-integer zooms. Test: `planChunks` round-trip + grid coverage tests (Task 8), dev-runbook pixel check (Task 10).
2. **Hidden category leaking into an export pass** — a category hidden via eye toggle must never appear in any pass. Test: `applyPassMask` respects pre-set `visibility: 'none'` (Task 9).
3. **PSD layer order inverted** — ag-psd's first child is the TOP layer; wrong order silently hides geometry in AE. Test: `assemblePsd` read-back asserts children[0] is the top layer (Task 12).
4. **Requested size above 16,384 px accepted** — dialog must clamp. Test: ExportDialog clamp test (Task 13).
5. **Long export hangs UI or can't be cancelled** — cancel must stop between chunks and free the hidden map. Test: `runExport` abort test with fake renderer (Task 13).

### Task 8: Chunk planner (pure math)

**Files:**
- Create: `src/renderer/src/lib/chunkPlan.ts`

**Interfaces:**
- Consumes: nothing (pure).
- Produces:
```ts
export interface CropBounds { west: number; south: number; east: number; north: number }
export interface Chunk { col: number; row: number; centerX: number; centerY: number; lng: number; lat: number }
export interface ChunkPlan {
  zoom: number; chunkPx: number
  actualWidth: number; actualHeight: number          // px of bounds at zoom
  cols: number; rows: number; chunks: Chunk[]
}
export const MAX_EXPORT_PX = 16384
export function planChunks(bounds: CropBounds, longEdgePx: number, chunkPx?: number): ChunkPlan  // default chunkPx 2048; longEdgePx clamped to MAX_EXPORT_PX
export function lngLatToWorldPx(lng: number, lat: number, zoom: number): { x: number; y: number }
export function worldPxToLngLat(x: number, y: number, zoom: number): { lng: number; lat: number }
```
- Math: Web Mercator, 512 px tiles. `worldPx = longEdgePx / max(spanX, spanY)` where `spanX = (east-west)/360` (normalized), `spanY = yF(south) - yF(north)`, `yF(φ) = (1 - ln(tan(φ)+sec(φ))/π)/2`, lats clamped to ±85.051129. `zoom = log2(worldPx/512)`. `actualWidth = round(worldPx·spanX)`, `actualHeight = round(worldPx·spanY)`. Chunk centers: `(col·chunkPx + min(chunkPx, actualWidth − col·chunkPx)/2, …)`, row-major.

**Steps:**

  - Full-world bounds (`west:-180, east:180, south:-85.051129, north:85.051129`), `longEdgePx 4096`, `chunkPx 1024` → `zoom === 3`, `actualWidth === 4096`, `cols === 4`, `rows === 4`, `chunks.length === 16`; chunk `[0][0]` center world px `(512, 512)`, `lng === -135`, and `lngLatToWorldPx(lng, lat, zoom)` round-trips to `(512, 512)` within 1e-6.

  - `planChunks(bounds, 99999)` clamps: resulting `max(actualWidth, actualHeight) <= 16384`.
  - Latitudes beyond ±85.051129 are clamped, not NaN.
